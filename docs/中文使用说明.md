# RNAi Designer 中文使用说明

RNAi Designer 是一个面向植物 RNAi / ihpRNA / hpRNA 构建的候选片段设计工具。它的目标是从目标基因 CDS 或转录本序列中自动筛选 200-500 bp 左右的 RNAi trigger 片段，并评估这些片段可能产生的 21 nt siRNA、同源转录本命中情况、脱靶风险和靶位点可及性。

本工具适合以下场景：

- 已有目标基因 CDS / transcript FASTA，希望设计 RNAi 片段。
- 希望一个 RNAi 片段沉默目标基因及其高度同源基因或等位基因。
- 已有全物种转录本 FASTA，希望评估候选片段会命中哪些转录本。
- 希望输出可用于发卡 RNA 构建的 `sense + spacer + antisense` 序列。

## 一、基本原理

植物 RNAi 载体常用结构是：

```text
启动子
目标片段 sense 方向，约 200-500 bp
intron / spacer
目标片段 antisense 方向，约 200-500 bp
终止子
```

转录后形成发卡 RNA，双链区域会被 Dicer-like 蛋白切成一系列 21-24 nt siRNA，从而沉默目标转录本。

RNAi Designer 的核心逻辑是：

1. 在目标基因序列上按窗口扫描候选片段。
2. 将每个候选片段切成一系列 21 nt siRNA。
3. 计算 siRNA 的 GC、端稳定性、链选择倾向、A/U 富集等效率特征。
4. 如果输入多个目标序列，则进行全局序列比对，并统计候选 siRNA 是否能同时命中多个目标。
5. 使用 ViennaRNA / RNAplfold 等价算法计算靶区域 accessibility。
6. 使用 Bowtie2 对全转录组进行外部比对验证，统计候选 siRNA 会命中哪些转录本。
7. 输出候选片段表、候选 FASTA、构建 FASTA、siRNA 明细表和密度表。

## 二、和 si-Fi21 的关系

si-Fi21 的主要思想包括：

- 使用 Bowtie 做 siRNA 与数据库的序列相似性搜索。
- 对 siRNA 进行热力学和链选择评估。
- 使用 RNAplfold 评估 target accessibility。
- 以长 dsRNA / RNAi trigger 为单位综合评估候选区域。

RNAi Designer 对齐了这些核心模块：

- 内置候选片段滑窗和 21 nt siRNA 生成。
- 使用 Bowtie2 作为本地外部比对后端。
- 使用 ViennaRNA Python binding 的 `RNA.pfl_fold_up()` 计算 RNAplfold-equivalent accessibility。
- 输出每条 siRNA 的命中、效率和 accessibility 信息。

注意：Bowtie2 后端不是 si-Fi21 原始 Bowtie 1 后端的完全同一程序，但在 Windows 上更容易本地部署和运行。本工具也保留 Bowtie 1 接口，若系统中有可用 Bowtie 1，可使用 `--bowtie-index` 调用。

## 三、安装和启动

### Windows 一键部署

在软件目录下运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\bootstrap.ps1
```

检查依赖：

```powershell
scripts\run.ps1 --check-deps
```

如果显示 ViennaRNA Python bindings 和 Bowtie2 aligner/indexer 为 `OK`，说明本地完整功能可用。

### Linux / macOS

```bash
bash scripts/bootstrap.sh
bash scripts/run.sh --check-deps
```

Linux / macOS 下建议通过 conda、brew、apt 或官方包安装 Bowtie2。ViennaRNA Python binding 会由 bootstrap 脚本安装到本地环境。

## 四、输入文件

### 1. 目标序列 FASTA

可以是一个目标基因：

```fasta
>GeneA.1
ATGG...
```

也可以是多个目标基因或等位基因：

```fasta
>Hap1_GeneA
ATGG...
>Hap2_GeneA
ATGG...
```

如果是一个目标序列，软件会在该目标上设计 RNAi 片段，然后用全转录组评估可能命中的同源转录本。

如果是多个目标序列，软件会把第一条作为 reference，并把其他目标序列比对到 reference 上，用于寻找多个目标共同可命中的候选区域。

### 2. 全转录组 FASTA

应包含该物种所有转录本或 CDS：

```fasta
>GeneA.1
ATGG...
>GeneB.1
ATGG...
>GeneC.1
ATGG...
```

这个文件用于：

- 建 Bowtie2 索引。
- 评估候选 siRNA 会命中哪些转录本。
- 识别目标基因的高度同源转录本或潜在等位基因。

## 五、常用命令

### 单目标基因设计

```powershell
scripts\run.ps1 `
  --targets target.fa `
  --transcriptome all_transcripts.fa `
  --out-prefix results/GeneA `
  --min-len 300 `
  --max-len 450 `
  --step 25 `
  --accessibility-method rnaplfold `
  --require-rnaplfold `
  --build-bowtie2-index results/bt2/all_transcripts `
  --max-candidates 10
```

### 多目标或等位基因共同设计

```powershell
scripts\run.ps1 `
  --targets hap_targets.fa `
  --transcriptome all_transcripts.fa `
  --out-prefix results/GeneA_haplotype `
  --min-len 300 `
  --max-len 450 `
  --min-alignment-identity 0.80 `
  --min-shared-fraction 0.50 `
  --accessibility-method rnaplfold `
  --build-bowtie2-index results/bt2/all_transcripts
```

### 复用已有 Bowtie2 索引

第一次运行可使用：

```powershell
--build-bowtie2-index results/bt2/all_transcripts
```

之后同一个全转录组可以直接复用：

```powershell
--bowtie2-index results/bt2/all_transcripts
```

## 六、输出文件

假设 `--out-prefix results/GeneA`，会输出：

```text
results/GeneA_candidates.tsv
results/GeneA_candidates.fa
results/GeneA_constructs.fa
results/GeneA_sirnas.tsv
results/GeneA_density.tsv
results/GeneA_bowtie2.tsv
```

### 1. `_candidates.tsv`

候选 RNAi 片段汇总表。常用列：

```text
rank
candidate_id
reference_id
start
end
length
gc_percent
total_sirnas
efficient_sirnas
mean_sirna_score
mean_accessibility
min_alignment_identity
min_shared_fraction
offtarget_transcript_count
score
sequence
```

解释：

- `rank`：候选片段排名。
- `candidate_id`：候选片段 ID。
- `reference_id`：参考目标序列 ID。
- `start` / `end`：候选片段在参考目标序列上的坐标，1-based。
- `length`：候选片段长度。
- `gc_percent`：候选片段 GC 百分比。
- `total_sirnas`：该片段可产生的 unique 21 nt siRNA 数。
- `efficient_sirnas`：通过效率阈值的 siRNA 数。
- `mean_sirna_score`：平均 siRNA 效率分。
- `mean_accessibility`：平均 accessibility。
- `min_alignment_identity`：多个目标输入时，各目标投影区域的最低 identity。
- `min_shared_fraction`：多个目标输入时，候选 siRNA 在所有目标中的最低共享比例。
- `score`：综合评分，越高越优。
- `sequence`：推荐 RNAi trigger 片段序列。

### 2. `_candidates.fa`

候选 RNAi stem 片段 FASTA，可用于后续引物设计或构建。

### 3. `_constructs.fa`

候选发卡结构序列：

```text
sense fragment + spacer + antisense reverse-complement fragment
```

默认 spacer 是一段 `N` 占位符。实际构建时可用载体自带 intron 或 spacer 替换。

### 4. `_sirnas.tsv`

每条 21 nt siRNA 的明细表。常用列：

```text
candidate_id
offset
sirna
seed_2_8
gc_percent
efficiency_score
accessibility
antisense_5p_stability
passenger_5p_stability
asymmetry
au_5p_7
guide_preferred
present_in_TARGET
offtarget_hit_count
offtarget_transcript_count
max_offtarget_risk
offtarget_hits
```

解释：

- `offset`：该 siRNA 在候选片段中的起始位置。
- `sirna`：21 nt siRNA 序列。
- `seed_2_8`：seed 区域。
- `efficiency_score`：启发式效率评分。
- `accessibility`：该位置 RNAplfold-equivalent accessibility。
- `asymmetry`：端稳定性不对称程度，影响 guide strand 选择。
- `guide_preferred`：是否倾向形成有效 guide strand。
- `present_in_TARGET`：是否命中输入目标序列。
- `offtarget_hits`：内部扫描得到的命中详情。

### 5. `_density.tsv`

候选片段每个位置被多少 siRNA 覆盖，适合画类似 si-Fi 的区域密度图。

### 6. `_bowtie2.tsv`

Bowtie2 外部验证结果。常用列：

```text
query_id
transcript_id
position
strand
mismatches
```

解释：

- `query_id`：某个候选片段中的某条 siRNA。
- `transcript_id`：被命中的转录本。
- `position`：命中位置。
- `strand`：正链或反链。
- `mismatches`：错配数。

如果某个候选片段的很多 siRNA 都命中同一个非目标转录本，说明这个片段可能会共同沉默该同源转录本。

## 七、参数说明

### 输入输出参数

```text
--targets
```

目标序列 FASTA。可以包含一个或多个目标。

```text
--transcriptome
```

全转录组或全 CDS FASTA。

```text
--out-prefix
```

输出文件前缀。例如 `results/GeneA`。

```text
--check-deps
```

检查 Python、ViennaRNA、Bowtie / Bowtie2 是否可用。

### 候选片段长度和滑窗参数

```text
--min-len
```

候选片段最小长度，默认 300。

```text
--max-len
```

候选片段最大长度，默认 450。

```text
--step
```

滑窗步长，默认 25。步长越小，搜索越细，但速度越慢。

```text
--sirna-size
```

siRNA k-mer 长度，默认 21。

### 多目标共同命中参数

```text
--min-alignment-identity
```

多个目标输入时，候选区域在所有目标中的最低比对 identity。默认 0.85。

```text
--min-shared-fraction
```

多个目标输入时，候选 siRNA 在所有目标中可共享命中的最低比例。默认 0.70。

```text
--max-target-mismatches
```

统计目标之间共享 siRNA 时允许的错配数。默认 0。

如果是等位基因，建议保持 0 或 1。

如果是同一家族不同基因，允许 2-3 个错配可以用于探索，但不建议把结果直接当成强 RNAi 命中。

### siRNA 效率参数

```text
--min-efficient-sirnas
```

候选片段至少需要多少条高效 siRNA。默认 5。

```text
--efficient-sirna-score
```

单条 siRNA 被视为高效的最低分数。默认 1.5。

siRNA 效率分综合考虑：

- GC 含量。
- 5' 端 A/U 特征。
- 端稳定性不对称。
- A/U 富集。
- seed 区域。
- 低复杂度惩罚。

### 脱靶和命中参数

```text
--max-offtarget-transcripts
```

内部扫描允许命中的非目标转录本数量。默认 0。

特殊值：

```text
--max-offtarget-transcripts -1
```

跳过内部逐序列扫描。大转录组时推荐这样做，然后使用 Bowtie2 外部验证。

```text
--max-offtarget-mismatches
```

内部扫描时允许的错配数，默认 1。

```text
--offtarget-seed-size
```

内部近似扫描使用的 seed 大小，默认 12。

### GC 和低复杂度过滤

```text
--min-gc
```

候选片段最低 GC 百分比，默认 30。

```text
--max-gc
```

候选片段最高 GC 百分比，默认 60。

```text
--max-homopolymer
```

允许的最长单碱基连续重复长度，默认 8。

### Accessibility 参数

```text
--accessibility-method
```

可选：

```text
none
heuristic
rnaplfold
```

推荐使用：

```text
--accessibility-method rnaplfold
```

该模式会使用 ViennaRNA Python binding 或 RNAplfold 可执行文件计算 unpaired probability。

```text
--require-rnaplfold
```

如果无法使用 ViennaRNA / RNAplfold，则直接报错，不自动降级。

```text
--rnaplfold-window
```

RNAplfold 窗口大小，对应 `-W`，默认 80。

```text
--rnaplfold-span
```

RNAplfold 最大配对跨度，对应 `-L`，默认 40。

### Bowtie / Bowtie2 参数

```text
--bowtie-index
```

使用已有 Bowtie 1 索引。

```text
--bowtie-executable
```

Bowtie 1 可执行文件路径。

```text
--bowtie2-index
```

使用已有 Bowtie2 索引。

```text
--build-bowtie2-index
```

从 `--transcriptome` 自动构建 Bowtie2 索引，并用于当前分析。

第一次分析某个全转录组时使用这个参数。之后可复用 `--bowtie2-index`。

```text
--bowtie2-executable
```

Bowtie2 aligner 路径。

```text
--bowtie2-build-executable
```

Bowtie2-build 路径。

### 输出数量和构建参数

```text
--max-candidates
```

最多输出多少个候选片段，默认 25。

```text
--spacer
```

构建 FASTA 中 sense 和 antisense 之间的 spacer。默认是一段 `N`。

## 八、结果解读建议

### 1. 选择候选片段

优先选择：

- `score` 高。
- `length` 在 300-450 bp。
- `efficient_sirnas` 多。
- `mean_accessibility` 高。
- Bowtie2 命中目标基因及预期同源基因多。
- 对不想沉默的基因命中少。

### 2. 判断是否能沉默同源基因

看 `_bowtie2.tsv` 或整理后的命中汇总：

- 如果某个同源转录本被大量 siRNA 命中，尤其 ≤1 mismatch 命中很多，说明可能被共同沉默。
- 如果只有 1-3 条 siRNA 命中，通常只能算弱风险或弱共沉默可能。
- 如果完全没有 21 nt 或近似匹配，则不建议认为可以沉默。

### 3. 判断是否适合同时沉默两个不同基因

不同基因即使同属一个家族，也可能只有蛋白层面保守，核酸层面的连续 21 nt 保守很少。

如果两个基因之间：

- 300 bp 窗口里共享 21 nt 很少；
- `min_shared_fraction` 很低；
- 多目标模式输出 0 candidates；

则不建议强行设计一条 RNAi 片段同时打两个基因。更推荐分别设计。

## 九、常见工作流

### 工作流 A：一个目标基因，找能一起沉默的同源基因

```powershell
scripts\run.ps1 `
  --targets GeneA.fa `
  --transcriptome all_transcripts.fa `
  --out-prefix results/GeneA `
  --min-len 300 `
  --max-len 450 `
  --max-offtarget-transcripts -1 `
  --accessibility-method rnaplfold `
  --require-rnaplfold `
  --build-bowtie2-index results/bt2/all
```

然后查看：

```text
results/GeneA_candidates.tsv
results/GeneA_bowtie2.tsv
```

### 工作流 B：两个 haplotype 等位基因共同设计

```powershell
scripts\run.ps1 `
  --targets Hap1_Hap2.fa `
  --transcriptome all_transcripts.fa `
  --out-prefix results/GeneA_hap `
  --min-alignment-identity 0.85 `
  --min-shared-fraction 0.70 `
  --max-target-mismatches 0 `
  --accessibility-method rnaplfold `
  --bowtie2-index results/bt2/all
```

### 工作流 C：探索家族共沉默

```powershell
scripts\run.ps1 `
  --targets GeneA.fa `
  --transcriptome all_transcripts.fa `
  --out-prefix results/GeneA_family `
  --max-offtarget-transcripts -1 `
  --accessibility-method rnaplfold `
  --bowtie2-index results/bt2/all
```

然后根据 Bowtie2 命中结果判断哪些家族成员会被连带沉默。

## 十、注意事项

1. RNAi 预测不是实验保证。最终片段仍建议结合 qPCR、转录组或小 RNA 测序验证。
2. 仅凭转录本命中不能严格证明等位基因关系。等位基因鉴定最好结合基因组位置、共线性、haplotype 注释和系统发育。
3. 一个片段同时沉默多个不同基因时，脱靶和表型解释会更复杂。
4. 300-450 bp 通常是较稳妥的植物 RNAi trigger 长度，但具体载体和物种可调整。
5. 如果全转录组很大，建议跳过内部扫描：`--max-offtarget-transcripts -1`，用 Bowtie2 输出做判断。
6. Windows 下 Bowtie 1 旧版二进制可能缺少运行时 DLL；本软件默认推荐 Bowtie2 本地后端。

## 十一、推荐报告写法

如果只是根据 Bowtie2 命中识别同源转录本，建议写：

```text
根据全转录组 siRNA 命中分析，该候选 RNAi 片段预计可同时靶向目标基因及若干高度同源转录本。
```

如果没有基因组共线性证据，不建议直接写：

```text
该片段同时靶向两个已鉴定等位基因。
```

更严谨的写法是：

```text
候选 RNAi 片段对目标转录本及其高度同源转录本具有大量 21 nt siRNA 命中，提示其具有共同沉默潜力。
```
